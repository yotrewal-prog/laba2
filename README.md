# mathtool

Консольное приложение для расчётов над уравнениями и числовыми
последовательностями. Лабораторная работа № 2 «Обработка числовых рядов»,
продолжение работы № 1 (решение уравнения).

## Состав репозитория

    mathtool.py          точка входа: выбор команды, ввод-вывод
    cli.py               разбор параметров командной строки (argparse)
    calc/                пакет с расчётной частью
        __init__.py      пустой файл, отмечающий каталог как пакет
        equation.py      решение уравнения
        stats.py         показатели последовательности
        series.py        сумма ряда
        integration.py   численное интегрирование
    numbers.txt          пример входных данных для команды stats
    tests.txt            набор тестов
    main.py              файл из первой работы, не изменяется
    README.md
    .gitignore

## Запуск

Приложение запускается из каталога репозитория: файлы данных открываются
относительно текущего каталога, а модули ищутся в каталоге файла программы.

    python mathtool.py                            общая справка
    python mathtool.py --help                     общая справка
    python mathtool.py <команда> --help           справка по команде

## Команды

### solve — решение уравнения A*x^2 + B*x + C = 0

    python mathtool.py solve -a 1 -b -3 -c 2      коэффициенты заданы
    python mathtool.py solve                      коэффициенты с клавиатуры

Коэффициенты A, B, C — целые числа, по модулю не более 10000. Указываются
либо все три, либо ни одного.

### stats — показатели числовой последовательности

    python mathtool.py stats --input numbers.txt  числа из файла
    echo "4 1 5" | python mathtool.py stats       числа из конвейера
    python mathtool.py stats                      числа с клавиатуры

Чисел не более 20, значения — конечные вещественные, по модулю не более
10000. Показатель, которого не существует, выводится как НЕ СУЩЕСТВУЕТ
(код возврата при этом остаётся 0).

### series — сумма числового ряда

    python mathtool.py series --func sqplus --terms 6
    python mathtool.py series --func sqplus --eps 0.0001

Указывается ровно один из параметров --terms (остановка по количеству
слагаемых) и --eps (остановка по достигнутой точности).

Ряды: sqplus, third, triplus, halfsq, nsqplus, nnext, ncube.

### integrate — численное интегрирование

    python mathtool.py integrate --func ratio --from 0 --to 20 --steps 1000

Интеграл вычисляется методом левых прямоугольников. Оба предела должны
лежать в допустимом промежутке функции.

Функции: ratio, root, exp, logsq, invroot, logcube.

## Коды возврата

    0 — расчёт выполнен;
    1 — ошибка в данных;
    2 — ошибка в командной строке (сообщение argparse).

Сообщения об ошибках выводятся в стандартный поток ошибок с префиксом
«ОШИБКА: ».

## Тесты

Набор тестов — в файле tests.txt: каждый тест записан блоком с полями
«Команда», «stdin», «stdout», «stderr» и «Код возврата». Проверка набора:

    cd /путь/к/репозиторию
    python mathtool.py stats --input numbers.txt

Приложение проверяется на каждом тесте набора; несовпадение с ожидаемым
означает необходимость исправления приложения.

## История изменений

Работа выполнена отдельными коммитами по этапам:

1. перенос решения уравнения в модуль calc.equation;
2. переход на разбор параметров средствами argparse (cli.py);
3. точка входа и обработчики команд;
4. команда stats;
5. команда series;
6. команда integrate;
7. набор тестов и документация.
